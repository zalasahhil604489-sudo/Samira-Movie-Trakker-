# Samira's Screen Club

A colorful movie tracker made with HTML, CSS, and a little JavaScript.

## Files
- `index.html` — the main website page
- `style.css` — bright tropical colors and responsive design
- `script.js` — navigation, light/dark themes, search, and movie list actions

## Open the website
Keep all four files together in the same folder and open `index.html`.

## GitHub
Upload all four files directly into the root of your repository.
